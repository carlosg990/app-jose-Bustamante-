# Liga MX App ⚽

App web para fans de la Liga MX que incluye:

- 🧩 Bracket de liguilla
- 🎮 Fantasy de equipos
- 📊 Quiniela de predicciones
- ⏱ Resultados en tiempo real (en desarrollo)

## Tecnologías
- HTML
- CSS
- JavaScript

## Instalación
1. Clonar repo
2. Abrir index.html
