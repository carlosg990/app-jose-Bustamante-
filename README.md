# ⚽ Liga MX Web App

A modern, interactive Web Dashboard for **Liga MX** football fans. Build your bracket for the *Liguilla*, draft your dream squad in *Fantasy*, and place predictions in the real-time *Quiniela*.

## ✨ Features

- 🏆 **Liguilla Bracket:** Interactive playoff predictor with local state persistence.
- ⚽ **Fantasy League:** Select and manage your top 5 Liga MX teams.
- 📊 **Live Quiniela:** Fetch real-time fixtures and live odds/logos using the Football API (API-Sports).
- 💾 **Persistent Storage:** Saves user picks seamlessly using `localStorage`.
- 📱 **Responsive UI:** Dark-mode dashboard optimized for mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+ Modules), HTML5, CSS3 (Custom Variables & Glassmorphism)
- **API Integration:** [API-Football (v3)](https://www.api-football.com/)
- **State Management:** Browser `localStorage`
